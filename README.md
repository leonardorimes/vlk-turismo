# VLTurismo

Este projeto é o site da **VLTurismo**, uma plataforma para facilitar a compra de passagens e pacotes turísticos de forma prática e eficiente. O site está hospedado em [vlkturismo.com.br](https://vlkturismo.com.br).

## Tecnologias Utilizadas

- **React**: Framework JavaScript utilizado para criar a interface de usuário de maneira eficiente e reativa.
- **Supabase**: Banco de dados e backend como serviço, utilizado para armazenar e gerenciar dados da aplicação de forma rápida e escalável.
- **Tailwind CSS**: Framework CSS para criar um design responsivo e moderno de maneira rápida e intuitiva.

## Funcionalidades

- Interface limpa e responsiva, adaptada para dispositivos móveis e desktop.
- Integração com o Supabase para gerenciar dados de usuários e passagens.
- Design customizado com o uso de Tailwind CSS.
- Acesso rápido a pacotes turísticos e compra de passagens.
